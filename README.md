## XAUUSD Leverage Calculator

Enter account balance, desired lot size and gold price — get the leverage you need,
position value and gold quantity.

**Live:** https://0xshaikh.github.io/calculators/

- 1.00 lot = 100 oz of gold
- Position value = lots × 100 × gold price
- Required leverage = position value ÷ account balance
- Client-side validation, Enter key support, aria-live result
