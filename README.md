## Gold Leverage Calculator

Enter account balance, desired lot size and gold price — get the leverage you need,
position value and gold quantity instantly.

**Live:** https://0xshaikh.github.io/calculators/

- 1 standard lot = 100 oz (mini 50, micro 10 selectable)
- Position value = lots × contract size × gold price
- Required leverage = position value ÷ account balance
